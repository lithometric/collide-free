## Collide: cross-agent collision awareness (v{version}) — REQUIRED

Several agents and people edit this repo at once. Collide keeps them from
overwriting each other and hands each agent what the others already learned.
Its hooks run the protocol for you, with no tool calls:

- A **Collide briefing** arrives at session start and with each prompt: the
  exact signatures, callers, recent changes, notes and replayable recipes for
  the code you are about to touch. Build on it instead of re-reading files.
- The **gate** checks every write. When it blocks, it says why (a teammate's
  live change, or a numbered file whose number is taken, with the one now
  reserved for you): you MUST adapt to it, then retry.
- Every edit is **reported**, and the repo's check runs after writes; its
  verdict arrives in your next tool result.
- Lines starting with **Δ** in a tool result are teammates' changes since
  your last step: adapt to them, never undo them.

So while the hooks run, do not call `declare_intent`, `check_collisions`,
`report_edit` or `heartbeat`. Call a Collide tool only when it adds
something, and load every one you need in a single ToolSearch:

- `get_symbol` or `blast_radius`: a fact the briefing did not include.
- `defer_intent`: you are leaving work unfinished (it becomes a task).
- `send_agent_message` with `anchor="path.py::symbol"`: hand work to
  whoever is on that code.
- `remember` with `anchor`: a durable decision about specific code.
- `recap`, `explain_code`: what changed, why, and what it cost. Ask these
  first, not `git log`.
- `pending_reconciliations`: when told two agents' work collides.
  ADDITIVE RESOLUTION: keep both sides' work and merge them; never delete
  either. Reconcilers never spawn reconcilers.

**Semantic lint**: a finding means a teammate renamed, removed or
re-signatured a symbol you use. Apply a mechanical fix yourself; for a
judgment fix, fix it inline or spawn ONE fixer (`claude -p`, `codex exec`,
`gemini -p`) that verifies its work and must NEVER spawn further fixers.

**No Collide briefing in your context?** The hooks are not running on this
machine. Call `setup` with repo_id `{repo_id}`, then
run the one command it returns. Never install Python for Collide. If Collide reports an
**Identity split** (hooks reporting as another account), do the same: setup
re-mints under the current MCP login.
